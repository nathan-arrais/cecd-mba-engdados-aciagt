# Jornada de Desenvolvimento da Arquitetura

## Introdução
Neste projeto, desenvolvi uma arquitetura em nuvem utilizando o Google Cloud Platform (GCP) para implementar uma solução de Infraestrutura como Código (IaC). A solução foi criada com o Terraform, que automatiza o provisionamento de recursos na GCP.

## Objetivos
O objetivo principal deste projeto foi automatizar a criação de infraestrutura na nuvem para garantir escalabilidade, segurança e alta disponibilidade para os serviços implementados.

## Arquitetura

A arquitetura foi desenhada para atender a requisitos específicos, incluindo a criação de VMs, buckets de armazenamento, e redes.

- Utilizamos o Terraform para definir os recursos como código.
- A infraestrutura foi provisionada na GCP, com recursos como Compute Engine, Cloud Storage e redes privadas.

## Desafios
Durante o desenvolvimento da arquitetura, enfrentei desafios relacionados à configuração das credenciais de acesso à GCP e à automação do provisionamento de recursos de forma eficiente.

## Conclusão
O uso do Terraform permitiu que a infraestrutura fosse facilmente reproduzida em diferentes ambientes, tornando o processo de desenvolvimento mais ágil e menos propenso a erros humanos.
